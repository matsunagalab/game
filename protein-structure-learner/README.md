# Protein Structure Learner

three.js で作った、タンパク質構造を体で覚えるゲームです。「2つの蝶番からウイルスまで」を4章15ステージでたどります。スマートフォンの縦画面を基準に作り、横画面・タブレット・PC でも遊べます。

## 遊び方

`index.html` を開くだけです。1つのファイルに全部入っているので、サーバーもネットワークも要りません。

## 4つの章

| 章 | 構造の階層 | 遊び | 題材 |
|---|---|---|---|
| Chain | 一次・二次 | φ/ψ を指で動かしてラマチャンドラン図を「地図」として開拓する | アラニン・グリシン・プロリンのペプチド |
| Beat | 配列から構造へ | 相手を向く残基をマスで点灯して規則を見つけ、最後は実配列を読んでヘリックスかストランドかを当てる | GCN4、ナノボディ、実タンパク質の13断片 |
| Core | 三次 | ヘリカルホイールを読み、油の面をコアへ向けて閉じる | GCN4、フェリチン、ミオグロビン、GFP |
| Shell | 四次 | 1つを回すと全コピーが連動し、殻が閉じる | HIV プロテアーゼ、コレラ毒素、フェリチン24量体、STNV 60量体 |

## 科学的な中身

- 座標はすべて PDB の実データ（2HHB, 2ZTA, 1MEL, 1MBN, 2FHA, 1EMA, 1HSG, 3CHB, 2BUK）です。
- ラマチャンドラン図は、ゲーム内の原子モデルから剛体球の判定で計算しています。接触距離は Ramakrishnan & Ramachandran (1965) の値です。α領域が理想の結合角では外れるため、蝶番に隣り合う原子対の判定を 0.15 Å 緩めています。
- GCN4 の埋没位置はヘプタッドの a と d です。ストランドの内向き・外向きは、実際の主鎖から求めた Cβ の向きで判定しています。
- 読解問題の13断片は、正解の折り方のほうが油が片面に集まるものだけを選びました（疎水モーメント, Eisenberg 1982）。
- Core の油の面の向きは、実際の側鎖の位置から求めた疎水モーメントです。向きがはっきりしないヘリックスとストランドはダイアルにせず、最初から固定しています。

## 作り直す

```sh
# PDB ファイルを1つのフォルダに集めてからデータを作る
node tools/build_data.mjs PDBのフォルダ

# index.html を作る（esbuild は npx が取ってくる）
node tools/build.mjs
```

`node_modules` は置いていません。Google Drive の同期を避けるためです。three.js は `vendor/three/` に同梱しています。

## フォルダ

- `src/press.js`: 3色インクの印刷エンジン（すべての画面がここを通る）
- `src/ribbon.js`: リボンと空間充填の描画
- `src/peptide.js`: φ/ψ からの鎖の組み立て、衝突、水素結合
- `src/chapters/`: 4章それぞれのゲーム
- `src/stages.js`: ステージの定義と説明文
- `tools/`: データ生成とビルド
